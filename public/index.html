Skill review

Checks a Claude skill against Anthropic's skill-authoring standards, then tests it with evals: does it trigger on the right prompts, and does it beat no skill at all?

How the review works

1 · Static checks (instant, repeatable)

About 40 rules from the Agent Skills spec and Anthropic's skill authoring best practices: name and description rules, a body under 500 lines, references one level deep, a contents list in long files, no time-sensitive wording, examples, an output format, evals shipped. Packaging rules add secrets, .env files, dependency folders and junk files. Blocker −40, major −15, minor −5 per category; categories are weighted 25/20/20/15/20.

2 · AI review (Claude reads the skill)

Claude scores seven dimensions from 1 to 5: trigger precision, clarity, token economy, degrees of freedom, edge cases, output spec and safety. It also drafts an eval suite: should-trigger prompts, near-miss prompts that should not trigger, and self-contained task cases with checkable assertions.

3 · Evals (does it work, and beat no skill?)

Trigger test: Claude picks a skill for each prompt from this skill plus decoys, which gives accuracy, precision and recall. A/B test: each task runs with the skill and without it, and a blind grader scores both against the assertions. These runs are simulated: no tools, inputs inline. Run the exported evals.json in Claude Code with skill-creator for full tool-using runs.

Release gate. Pass means no blockers, no majors and a score of at least 75, plus, once evals have run, trigger accuracy of at least 80% and a with-skill pass rate at or above baseline. Conditional means no blockers but something short of Pass. Fail means at least one blocker.
